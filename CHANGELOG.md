## [0.1.0] - 2026-03-19

### Added

- Pattern browse view with card-based layout
- Semantic search with tag, language, domain, and agent filters
- Pattern detail view with metadata, content, chunks, related patterns, and agent associations
- Related-pattern pivoting inside the detail pane
- Single-file Markdown pattern import with client-side validation
- Loading, empty, and error states across browse, search, detail, and import flows
- UI and end-to-end tests for main workspace flows
- Contributor-facing setup and usage documentation
- API contract alignment (Phase 2) — response handling matches mnemonic-api v1 spec
- Project planning documents: PRD, screen map, use case diagram, tech stack justification
- ADR 0001: frontend stack and build strategy (React 19, TypeScript, Vite, TanStack Query, Tailwind CSS, Playwright)
